 # 🌐 Personal Portfolio Website  

Welcome to my interactive **portfolio website**, a creative space where I showcase my skills, projects, and achievements as a web developer.  
This portfolio is designed to be **modern, fast, and engaging**, with animations and 3D elements that bring a unique experience for visitors.  

---

## ✨ Features  

- 🎨 **Modern UI/UX** – Clean, responsive, and visually appealing design with TailwindCSS.  
- ⚡ **Smooth Animations** – Leveraging **GSAP** for scroll-triggered and timeline animations.  
- 🌀 **3D Interactive Models** – Integrated **Three.js** + `@react-three/fiber` for immersive visuals.  
- 📩 **Contact Form Integration** – Powered by **EmailJS**, making communication seamless.  
- 🔎 **Project Highlights** – Showcases my projects, certificates, and journey in tech.  
- 📱 **Responsive Design** – Fully optimized for mobile, tablet, and desktop devices.  

---

## 🛠️ Tech Stack  

- **Frontend:** React.js, TailwindCSS, JavaScript (ES6+).  
- **3D & Animations:** GSAP, Three.js, @react-three/fiber, @react-three/drei.  
- **Forms & Backend Services:** EmailJS for handling messages.  
- **Version Control:** Git & GitHub.  
- **Hosting/Deployment:** (Planned: Vercel / Netlify / AWS).
